# Security Policy

## Supported versions

The latest published `1.x` release receives security fixes.

## Reporting

Report vulnerabilities through GitHub's private security advisory process. Do not include credentials, session transcripts, or target data in a public issue.

## Operational warnings

This plugin can read cross-project session text, interrupt sessions, and recursively delete sessions. Automatic permissions are opt-in. Use exact session confirmation for deletion and restrict permissions when untrusted agents can access the server.
